# Native rewrite parity ledger

This is a release checklist, not evidence that the native features exist. All rows are **pending**. Record a native test/report and result against every row before NR37. [Architecture](native-rewrite.md) and [task queue](native-rewrite-tasks.md) define implementation boundaries.

Source baseline: `rt` release 0.9.57 at `5ea5c22310ff`. Rows were first written against 0.9.43 (`e6583d2a3e66`) and were reconciled with every later commit on 2026-10-30. The Go terminal app under `rt/tui` is a separate product and is out of scope here; the native app must still interoperate with it as another writer on the same format 1 notebook, including its deterministic merges and status heartbeats (E14, E18).

The 47 S-rows below preserve each row of the [source storage inventory](../../rt/plans/storage-engine-inventory.md), in the same order. Source test names refer to `rt/tests/<name>.test.ts` or `.tsx`, its `tests/e2e/` directory, or its named scripts. They are behavioral references; a passing legacy test does not prove native parity. Cache mechanisms can change while their correctness/performance contract stays covered.

## Known source limitations to preserve honestly

The source README lists incomplete native composition/accessibility/Windows verification, no cross-file undo, no standalone fenced-code references, and no complete rich-formatting toolbar. Page and folder deletion exists since 0.9.45 but has no in-app restore. Tasks have no recurrence, priority, or schedule engine; `{{tasks: QUERY}}` lists exist, but the desktop shows the terminal app's `{{query: ...}}` blocks and `key:: value` properties as ordinary text. Imported Roam JavaScript is not executed, and Roam SmartBlock template commands are no longer read since 0.9.55. These are not accidental native regressions, and source limitations do not waive this plan's explicit native input and platform acceptance gates.

The source storage plan still contains incomplete lazy queries, real-provider measurements, and export/failure evidence despite some tasks being marked done. Those are covered by the queue rather than inherited as verified behavior.
